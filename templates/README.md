# Шаблоны

Копируемые шаблоны из [Agentic Development Playbook](../README.md). Каждый
предназначен для копирования в новый проект целиком, с последующей заменой
полей-заглушек `<...>`.

| Файл | Для чего | Откуда в документе |
|---|---|---|
| [`AGENTS.md`](AGENTS.md) | Инструкция для агента в репозитории: роли, стек, правила, контракты, гейты, канон | §4 |
| [`spec.md`](spec.md) | Спецификация задачи (ТЗ): позиционирование, метрики, scope, сценарии, UX, данные, платежи, админка, инфраструктура, тесты, риски | §5 |
| [`handoff.md`](handoff.md) | Передача состояния между агентами/итерациями | §9 |
| [`review-checklist.md`](review-checklist.md) | Чек-лист ревью AI-кода (пункты `[gate]` обязаны быть в CI) | §6 |
| [`secrets-checklist.md`](secrets-checklist.md) | Чек-лист безопасности секретов | §7 |

## Как использовать

1. Скопировать нужный файл в корень нового проекта.
2. Заменить все `<...>` на реальные значения. Поле без заполнения — незаполненный
   контракт; агент его не получит.
3. Удалить разделы, которые не применяются, явно (строкой «не применяется: причина»),
   а не молча.
4. Проверить: `python3 scripts/check-templates.py`.

## Правила

- Заглушки только в виде `<имя>` или `<путь>`. Синтаксис `{{ }}` не используется:
  это шаблонизатор, а не контракт.
- В шаблонах нет реальных имён, хостов, IP, токенов. Примеры — из зарезервированных
  диапазонов (`192.0.2.10`, `+7 (999) 000-00-00`).
- Шаблон не дублирует документацию: он короткий и копируется. Объяснения — в
  README и в главах, не здесь.
